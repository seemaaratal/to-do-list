📝 To-Do List Application

A simple and user-friendly To-Do List application developed using HTML, CSS, and JavaScript. It helps users organize their daily tasks and manage their activities easily.

✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and attractive user interface
- Easy task management

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📂 Project Structure

ToDoList/
│
├── todolist.html
├── style.css
├── todolist.js
└── README.md

🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open "todolist.html" in your web browser.
4. Start adding and managing your tasks!
